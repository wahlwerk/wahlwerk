## How `tally.csv` was made

From the wahlwerk-data bundle (itself generated by wahlwerk-data-processing from the
workbook, with all 822 published sums checked), with the engine:

```python
vote = PopularVote.from_key("de.landtag.st.2026", "../wahlwerk-data")
votes = vote.tally.filter(kind="votes").sum_to("wahlkreis")
votes.sum_by("unit", "section", "party", "candidate")  # one row each, channel left blank
```

Invalid votes, Wahlberechtigte and Wähler are left out: the seat allocation does not use
them. Einzelbewerber appear as `de.st.wk.<nr>.einzelbewerber`, the workbook's sum of all
Einzelbewerber in a Wahlkreis; none of them won one.
