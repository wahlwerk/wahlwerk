# wahlwerk

Electoral and parliamentary systems as rules-as-code: a deterministic engine
parameterised by an electoral law, so that small changes to the law can be evaluated
against real historical votes.

This is the **reference**: every package, class, function, field and parameter, read
from the code. What the pieces mean and how they work together, with sketches and real
elections, is on the website, [wahlwerk-site](https://wahlwerk.github.io/wahlwerk-site/).
